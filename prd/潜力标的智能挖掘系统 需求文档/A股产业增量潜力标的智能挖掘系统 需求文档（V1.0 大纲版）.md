A股产业增量潜力标的智能挖掘系统 需求文档（V1.0 大纲版）
定位：以公告事件为触发、基本面为底盘、产业增量为核心判断标准的自动化标的筛选工具；本大纲为顶层框架，后续可由专项 Agent 分模块填充规则、算法与实现细则。
一、项目概述
1.1 项目背景
A 股市场中，传统企业通过并购、跨界扩产、业务转型切入高景气赛道（AI 算力、AI + 医疗诊断、AI + 药物研发、先进材料等）的事件，往往带来公司基本面的长期重塑与价值重估（如中际旭创并购苏州旭创的经典转型案例）。但此类信息分散在每日上千份公告中，人工巡检覆盖不全、效率低下，易错过早期布局窗口；同时市场存在大量 “蹭热点” 式伪转型，甄别成本高。
1.2 核心目标
1. 自动化定时巡检全市场公告，精准识别跨界转型、产能扩张、并购整合等高价值事件信号；
2. 结合公司基本面与产业赛道逻辑，过滤纯题材炒作标的，筛选具备真实产业增量潜力的公司；
3. 输出标准化分析结论，为投研提供前置性的标的储备与跟踪清单。
1.3 项目定位
投研辅助工具，聚焦「事件驱动 + 基本面验证 + 产业增量逻辑」三重筛选，区别于短期题材选股，侧重长期基本面重塑的潜力标的挖掘。

2.2 第二层：基本面质量过滤层（风险排雷）
对初筛标的进行多维度基本面评分并说明。
1. 财务健康度
  - 无连续大额亏损，经营现金流为正，具备基本业务造血能力；
  - 资产负债率处于行业合理区间，无大额债务违约风险；
  - 原有主业具备稳定营收基本盘，非纯壳公司。
2. 治理与执行力
  - 实控人、管理层无重大失信、违规记录；
  - 新业务核心团队具备对应行业从业经验优先（如中际旭创保留原创业团队负责经营的架构）；
  - 有过往成功转型、并购整合案例的公司加分。
3. 估值安全边际
  - 估值处于自身历史分位中下水平，未提前透支转型预期；
  - 总市值具备足够成长弹性空间。
2.3 第三层：产业增量价值层（核心判断）
结合产业知识库，评估新业务对公司的长期价值增量，是区分 “真转型” 与 “蹭热点” 的核心。
1. 赛道空间：新赛道所处行业阶段（导入期 / 成长期）、长期市场规模天花板，优先覆盖 AI 全产业链、AI + 医疗、AI + 医药、先进材料等高增长赛道；
2. 业务协同性：新业务与公司原有主业在技术、客户、产能、供应链上的协同程度，协同度越高转型成功率越高；
3. 行业格局影响：公司切入后是否可能改变行业供需格局，或成为核心环节的新供给方；
4. 业绩弹性：新业务达产后对公司营收、利润的贡献弹性，是否足以重塑公司基本面。
标杆命中示例（中际旭创 2017 年并购）
1. 信号层：重大资产重组公告，收购苏州旭创 100% 股权，交易对价接近公司净资产 5 倍，主营业务将从电机装备转向高速光模块；
2. 基本面层：原主业有稳定基本盘，交易方案保留原创业团队全面负责经营，治理架构保障执行力；
3. 价值层：光模块处于云计算 + 5G 高景气成长期，赛道空间大，并购后公司将跻身国内头部厂商，基本面实现完全重塑。
三、核心业务场景
3.1 日常定时巡检场景
- 触发机制：每日盘后固定频率自动执行，盘中可配置增量轮询；
- 执行流程：拉取最新公告 → 信号识别与打标签 → 基本面自动过滤 → 产业价值评分 → 输出当日新增潜力标的清单；
- 交付物：每日标的简报，包含触发事件、核心逻辑、风险提示、优先级分级。
3.2 单标的深度分析场景
- 触发机制：对高优先级标的自动生成深度分析报告，或人工指定标的生成；
- 交付结构：对标中际旭创案例的标准化框架
  1. 事件核心概述：公告核心内容、交易 / 项目基本信息
  2. 公司原有基本面：原主营业务、财务状况、行业地位
  3. 事件方案细节：交易对价、支付方式、架构设计、团队安排
  4. 新赛道产业分析：赛道空间、增长逻辑、行业格局
  5. 增量价值分析：业务协同性、业绩弹性测算、行业格局潜在影响
  6. 未来展望与风险提示
3.3 赛道定向挖掘场景
- 支持自定义赛道（如 AI + 药物研发、AI 医学影像、AI 算力上游材料等），定向筛选该赛道相关的跨界转型标的；
- 支持历史公告回溯，验证筛选逻辑的历史有效性。
四、核心功能模块
4.1 定时任务调度模块
- 支持配置巡检频率（增量轮询 + 全量同步）；
- 支持断点续传、异常自动重试、失败告警；
- 支持按公告类型、市场板块配置扫描范围。
4.2 公告解析与标签化模块
- 对接巨潮资讯等官方公告数据源，自动拉取与解析公告正文；
- NLP 实体抽取：自动识别交易金额、标的公司、赛道方向、核心产品等关键信息；
- 自动事件打标签：如「并购转型」「定增扩产」「AI + 医药」「新材料」等。
4.3 基本面数据整合模块
- 对接行情与财务数据源，自动拉取标的财务、估值、股本等数据；
- 内置基本面评分模型，自动输出质量分与风险预警；
- 支持财务指标阈值自定义配置。
4.4 产业知识库模块
- 维护高景气赛道知识库：包含产业链环节、核心产品、技术路线、对应标的映射；
- 支持新增赛道、更新产品映射关系，可扩展性优先；
- 内置 AI + 医疗、AI + 医药、AI 算力上游等默认赛道库。
4.5 标的分析与输出模块
- 自动生成标准化深度分析报告，支持 Markdown 格式导出；
- 标的池管理：支持纳入观察、跟踪、剔除等状态标记；
- 支持自定义报告模板与输出字段。
4.6 系统配置管理模块
- 筛选规则阈值可视化配置；
- 赛道库、关键词库的后台编辑功能；
- 用户权限与操作日志管理。
五、数据来源与依赖
1. 公告数据源：巨潮资讯网、沪深交易所官方披露平台，核心字段包含股票代码、公告标题、发布时间、公告类型、PDF 附件地址等；
2. 基本面与行情数据：A 股财务、行情、行业分类标准化数据；
3. 产业知识库：需持续运营维护的赛道与产品映射库；
4. 依赖说明：需确保数据源合规性与更新及时性。
六、非功能需求
1. 时效性：盘后公告 2 小时内完成全量解析与筛选，增量公告 15 分钟内完成识别；
2. 准确率：核心事件信号识别准确率≥90%，减少误判与漏判；
3. 可扩展性：支持新增赛道、新增筛选规则，无需重构核心逻辑；
4. 可回溯性：支持历史公告与筛选结果的回溯验证；
5. 稳定性：每日定时任务成功率≥99%，异常自动告警。
七、风险甄别机制（专项规则）
内置伪转型甄别规则，降低踩坑概率，满足以下多项特征的标的自动降权或剔除：
1. 原有主业与新赛道完全割裂，无任何技术、客户、产能协同；
2. 转型动作集中在行情火热期，行业低谷期无任何产业投入；
3. 落地方式以新设空壳公司、签署框架协议为主，无实质产线、研发团队、大额投入；
4. 研发费率长期极低，新业务无核心技术储备，纯依赖外协代工。
八、后续迭代扩展方向
1. 接入产业链调研、舆情数据，补充验证维度；
2. 增加回测模块，验证筛选策略的历史收益表现；
3. 对接量化交易系统，实现信号自动落地；
4. 增加风险预警维度，同步识别业务收缩、基本面恶化的标的。
